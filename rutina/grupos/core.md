# Core

- **Descanso entre series:** 45 s
- **Uso:** los viernes, como alternativa a Legs: si el usuario amanece bien → búlgaras; si amanece con agujetas/cargado → Core (decidido 2026-11-06).
- **Objetivo:** desarrollar abdominales y un core fuerte que ayude en la carrera (estabilidad de tronco y cadera).
- **Equipo:** barra de dominadas + suelo.

## Contenido actual
_Vigente desde: 2026-11-06 (punto de partida conservador; sin historial previo)_

1. Elevaciones de rodillas colgado en barra — 3 x 10 (controlado, sin balanceo). Progresión: más reps → piernas estiradas.
2. Plancha frontal — 3 x 30 s (cuerpo recto, glúteos apretados).
3. Plancha lateral — 2 x 20 s por lado.
4. Dead bug (bicho muerto) — 3 x 8 por lado (zona lumbar pegada al suelo).

Duración aprox.: 12–15 min.
